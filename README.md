# AutoML-Model-Benchmarking-Tool
# Machine Learning Benchmarking Tool

## Overview
Automatically trains and evaluates multiple
scikit-learn models on tabular datasets.

## Features
- Data preprocessing
- Feature engineering
- Model comparison
- Hyperparameter tuning
- Visualization

## Installation
pip install -r requirements.txt

## Usage
python train.py

## Results
| Model | Accuracy |
|---------|----------|
| RF | 92% |
| SVM | 89% |
